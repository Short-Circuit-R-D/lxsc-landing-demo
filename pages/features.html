Everything you need to light a room

One browser workspace takes you from a floor plan to a standards-checked PDF report.

Guided Quickstart wizard

Five steps cover geometry, workplane, compliance and physics. Then run an automated study or open Studio to lay out the fixtures yourself.

Three ways to define a room

Draw on the canvas with ORTHO 90° for square corners, type exact vertex coordinates, or import a floor plan from CAD.

CAD import and cleanup

Upload a .dxf or .dwg file up to 50 MB, choose the source unit, then split open-plan areas, merge rooms, rename them and import the one you need.

Standards built in

Search EN 12464-1 activities by keyword, category or edition and the target illuminance and uniformity fill in. Or set a custom target, or none.

Catalog and custom photometry

Browse the SC Catalog by application or upload .ies and .ldt files. Inspect the POLAR WEB (C0/C90) diagram, power, flux and efficacy of every luminaire.

Parametric layouts

Draw Grid, Staggered, Boundary and Linear patterns, set count or spacing, and delete single positions without breaking the grid.

Automate

Choose a mounting height and a grid strategy and let Studio test catalog luminaires, returning up to five ranked candidate solutions.

Rooms and solutions

Keep many rooms in one project and compare design alternatives side by side on the canvas, each with its own results.

Results you can read

A value chart, grid points and false color show where the light falls, while the compliance audit judges every workplane on illuminance, uniformity, overdesign and power density.

Reports you can hand over

Set paper size and margins, add a logo, cover image, project description and signature, then export a vector PDF.

Portable projects

Export a project as one .lxsc file for backup or sharing. Search, sort and duplicate projects from the dashboard.

Verifiable reports

Anyone can check a public report by its project ID in seconds, while private reports stay protected.
